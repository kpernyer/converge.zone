# Docs/Content Repo Agent Guide

Use for repositories that are primarily markdown/knowledgebase content.

Editing principles:

- Keep changes scoped to one topic
- Preserve heading hierarchy and link integrity
- Prefer explicit, testable wording over ambiguity
- Avoid broad formatting-only churn across unrelated files

Validation checklist:

- Verify changed links and relative paths
- Confirm tables/lists render as expected
- Ensure terminology matches existing taxonomy
- Add rationale when changing definitions/contracts

Workflow:

- Make atomic commits by theme
- Leave a short handoff note for policy-level changes
